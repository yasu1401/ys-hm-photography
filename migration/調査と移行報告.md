# FC2サイト調査・移行報告

調査日：2026年9月8日。元サイト： http://heartwarmingphotographer.web.fc2.com/

## 現在の到達点

GitHub Pagesへ配置できる確認版を`docs/`に作成しました。FC2のファイルや設定は変更していません。GitHubへのアップロード・Pagesでの公開・移行先への転送はまだ行っていません。

## 調査結果

- 既存メニューはTOP / PORTFOLIO / GALLERIES / PHOTO TIPS / GUEST GALLERIES / ABOUTの6項目。
- 現行の公開リンクから66ページを確認。60アルバムの写真掲載1,580件を維持。これは掲載件数であり、重複を除いた写真枚数とは異なります。
- トップはFlashスライドショー。設定XMLと22枚の元写真を取得できました。旧設定はランダム再生、移行版は編集しやすいリスト順・6秒間隔です。
- 原本保管は5,045ファイル・約241.5MB（公開リンクの巡回分）。管理画面で見つかった旧HTML2件も追加保管。
- 管理画面ではルート6,256項目、全体約268.61MB。**管理画面の全項目の完全バックアップではありません**。現行の表示に必要なファイルを取得したものです。
- Flash設定にある未使用サムネイル22件は取得できませんでした。22枚の表示用写真はすべて取得済みで、移行版にはサムネイルへの依存はありません。
- 原本はShift_JIS、HTML 4、IE7互換指定、固定幅の表組み、多量のスペーサー、画像文字、古い拡大表示スクリプトを使用していました。

## 移行時の問題と対応

|問題|対応|
|---|---|
|Flash写真が現代のブラウザで表示できない|元の22枚を使うJavaScriptスライドショーへ置換|
|固定幅・小さな文字・大量の空白|PC／スマートフォン対応の共通CSSへ整理|
|75px程度の小さなサムネイル|拡大画像から一覧用を作成し、遅延読み込み|
|見出しと表紙写真のリンク先の不一致|紹介欄の表紙写真がリンクする正しいアルバムへ6件修正|
|同じ画像データが重複|同一バイトの画像は共通参照。別写真の統合やトリミングはしない|
|FC2解析・広告・Flash・IE互換コード|公開用には移さず、原本のみに保管|
|将来の写真管理が難しい|アルバム別JSONに分離。並べ替え・追加・削除・差し替えに対応|
|旧い撮影メモと機材情報|文章を維持。ABOUTの古い活動情報は当時の記録として注記|

黒背景・金色のサイト名・元のメニューを維持しています。ギャラリー紹介46件、ゲスト紹介4件、PHOTO TIPS 22項目を引き継ぎました。撮影情報が付いていた28件のキャプションも復元しました。表紙写真は元サイトの選択を保持。トップ・アルバムとも縦写真を切り抜かず表示します。

PORTFOLIOの画面上には9分類、非表示のサブメニューには追加の「This and That」がありました。ページを失わないよう、PORTFOLIOの下に同ページへのリンクを残しました。

## 公開前に確認すること

1. トップ：旧Flashの22枚を復元した状態でよいか、別の写真を使うか。
2. ABOUT：メール・機材・更新頻度を現状に合わせるか、当時の記録として残すか。
3. ゲストギャラリー：既存のまま公開してよいか。
4. 管理画面で見つかった`1_Portrait.html`、`bottom.html`など現行メニュー外の旧ファイルを新サイトにも載せるか。現段階では原本に保管し、新メニューへ追加していません。未巡回の残りのファイルもFC2上に残っています。
5. GitHubのアカウント名とリポジトリ名（または既存リポジトリURL）。

これらの選定・公開判断は未確定です。確認版を作ることと、公開することを分けています。

## ファイルの扱い

`docs/`が公開用。`migration/original/`はGit除外の原本。RAW・大型の原本写真はリポジトリに保存しません。公開用画像は長辺最大1920px、一覧用は最大640px。旧トップの低解像度画像は無理な拡大保存をしていません。

初回変換の途中に作られた重複・不要な生成ファイルのみ整理しました。FC2原本は削除していません。`tools/import_fc2.py`と`tools/finish_import.py`は初回処理の記録です。以後の手修正もあるため、更新時に実行しないでください。
